# 主控板外设接口与电源规范

> 版本：V1.2  
> 适用平台：STM32H743VIT6  
> 设计定位：12V 输入、高性能红外循迹小车主控板  
> 本规范以《STM32H743VIT6_引脚分配表》和《STM32H743VIT6_外设端子分组表》为基础整理，并根据当前方案统一电源、接口和外接模块边界。
>
> **设计原则：外部模块负责自身功能电路，主控板主要负责 MCU、整车电源转换、接口、电平兼容、保护、滤波与控制信号。**

# 4. 12V → 5V 主 Buck

## 4.1 推荐器件

### TPS54627DDAR

定位：整板 5V 主电源。

关键规格：

- 输入：4.5V~18V
- 输出电流：最高 6A
- 同步降压
- 自适应接通时间 D-CAP2™ 模式
- 固定开关频率 650kHz
- 支持可调限流
- 软启动
- Power Good
- UVLO
- 过流/过温保护
- 支持强制 PWM

官方产品资料：
- https://www.ti.com.cn/product/cn/TPS54627

## 4.2 设计原则

TPS54627DDAR 负责产生统一的 5V 中间母线，不直接把 5V 母线理解成“纯模拟电源”。

必须通过后级分支和滤波形成：

```text
5V
├── 5V_DIG
├── 5V_A_ADC
└── 5V_A_LDO_IN
```

## 4.3 PCB 布局重点

- VIN 输入陶瓷电容必须紧靠芯片
- 高频输入回路面积尽可能小
- SW 节点铜皮尽量小
- SW → 电感距离短
- 输出电容靠近电感/芯片
- FB 走线远离 SW
- 不允许高速数字/模拟信号从 SW 下方穿过
- Buck 功率区域远离 ADC、IMU 与模拟接口
- 大电流地回路不要穿越模拟区域

# 6. 3.3V 模拟电源

## 6.1 最终推荐器件

### TPS7A2033PDBVR

本方案采用 **TPS7A2033PDBVR** 作为 3.3V 模拟电源的基础 LDO 单元。该型号为固定 3.3V 输出、300mA SOT-23-5 低噪声 LDO。

由于模拟负载按功能分域，建议采用 **2~3颗同型号 LDO 分别供电**，而不是让单颗 LDO 承担所有模拟外设。这样可以降低不同模块之间的电源耦合，并保留充足的单路电流余量。

关键规格：

- 最大输出电流：300mA
- 输入电压范围：1.6V~6.0V（最高 6.0V）
- 输出噪声：约 7 µVrms（典型）
- PSRR：1kHz 时 95dB
- 静态电流 IQ：6.5µA（典型）
- 低压差：300mA 时 140mV（最大）
- 输出精度：±1.5%（最大）
- 支持软启动
- 使能控制
- Power Good
- 过流保护 / 过热保护 / 欠压锁定
- -40°C~125°C 工作温度范围

官方产品资料：
- https://www.ti.com.cn/product/cn/TPS7A20

## 6.2 输入电源

**TPS7A2033PDBVR 禁止直接接 12V。**

其输入应来自：

```text
5V
 │
 └── 独立滤波
      │
      ▼
5V_A_LDO_IN
      │
      ▼
TPS7A2033PDBVR
      │
      ▼
3V3_A
```

推荐从 5V 主母线单独引出 `5V_A_LDO_IN`，不要从 `3V3_DIG` 再降压。

## 6.3 3V3_A 负载

当前主要考虑：

- STM32H743 VDDA
- STM32H743 VREF+
- ICM-42688-P
- IMU660RB
- 其他低功耗模拟模块
- 必要的小信号模拟前端

OPA4377 如果选择 3.3V 供电，也可接入 `3V3_A`。

## 6.4 余量原则

TPS7A2033PDBVR 单颗额定 300mA，因此不建议让单颗 LDO 接近满载工作。

建议每颗 LDO 按以下原则设计：

```text
单颗 LDO 额定：300mA
推荐长期工作电流：≤ 100~150mA
设计目标：额定电流至少保留约 2 倍裕量
```

如某一路预计超过 150mA，优先考虑拆分负载或更换更高电流 LDO，而不是让 TPS7A2033PDBVR 长期接近极限。

## 6.5 多路 LDO 分域建议

推荐至少预留以下电源域：

```text
5V_A_LDO_IN
 ├── TPS7A2033PDBVR #1 → 3V3_MCU_A
 │                         └─ H743 VDDA / VREF+
 │
 ├── TPS7A2033PDBVR #2 → 3V3_IMU_A
 │                         └─ ICM-42688-P / IMU660RB
 │
 └── TPS7A2033PDBVR #3 → 3V3_SENSOR_A
                           └─ 其他敏感模拟外设
```

实际是否安装第 2、3 颗，根据外接模块实际电流和噪声隔离需求决定。

### 命名约定

当只装配 1 颗 LDO 时，所有接口章节中的 `3V3_A` 均指该路输出。

当装配多颗 LDO 时，接口章节中的 `3V3_A` 为模拟电源域统称，实际连接按下表映射，原理图中必须以具体域名标注：

| 接口/负载 | 实际电源域 |
|---|---|
| H743 VDDA / VREF+ | `3V3_MCU_A` |
| IMU 接口（J_IMU Pin1） | `3V3_IMU_A` |
| OPA4377（3.3V 供电时）及其他敏感模拟外设 | `3V3_SENSOR_A` |

## 6.6 热设计

LDO 功耗近似：

```text
P_LDO ≈ (VIN - VOUT) × IOUT
```

在 5V → 3.3V 时：

```text
I = 0.05A → 0.085W
I = 0.10A → 0.17W
I = 0.15A → 0.255W
```

通过多颗 LDO 分摊负载，可以显著降低单颗器件的发热，并提高长期可靠性。

# 7. 5V_A 模拟电源分支

5V 主母线不直接“一条线全部并接”。

推荐：

```text
5V
 │
 ├── 磁珠/LC ──→ 5V_A_ADC
 │                  │
 │                AD7606
 │
 └── 磁珠/LC ──→ 5V_A_LDO_IN
                    │
                  TPS7A2033PDBVR
                    │
                  3V3_A
```

## 7.1 这样分支的目的

避免：

```text
AD7606瞬态电流
       ↓
污染 LDO 输入
       ↓
影响 3V3_A
```

也避免：

```text
3V3_A 模拟域负载变化
       ↓
反馈到 AD7606 的 5V 模拟供电
```

## 7.2 AD7606 电源

AD7606 原版支持单 5V 模拟供电，VDRIVE 支持 2.3~5V；同时集成输入缓冲、二阶抗混叠滤波和内部参考，因此其模拟供电应作为独立的 5V_A 模拟区域处理。

官方资料：
- https://www.analog.com/en/products/ad7606.html

# 8. 外接模块接口总原则

所有外接接口统一考虑：

- VCC
- GND
- 信号方向
- IO 电平
- 最大输出电流
- 接口保护
- 走线长度
- 是否需要串联阻尼电阻

## 8.1 外接电机驱动

电机驱动模块自身的 VM 电源：

> **直接来自电池，不经过主控板。**

主控板只提供：

- PWM
- DIR
- GND

这样避免电机大电流通过主控板连接器和地回路。

# 10. 编码器接口

## 10.1 左编码器 J_ENC_L

**4P**

```text
1  3V3
2  ENC_A
3  ENC_B
4  GND
```

对应：

- A → PA0
- B → PA1

**限制：仅允许 3.3V 逻辑输出。**

---

## 10.2 右编码器 J_ENC_R

**4P**

```text
1  3V3 / 5V
2  ENC_A
3  ENC_B
4  GND
```

对应：

- A → PC6
- B → PC7

Pin1 的 3V3 / 5V 通过 **0Ω 电阻（或跳线）二选一** 选择，不允许同时短接。

PC6/PC7 为 FT 脚，兼容 5V 数字输入。

如果两侧均使用 5V 编码器：

> 左编码器必须增加电平转换电路，或将两侧编码器统一更换为 3.3V 逻辑输出版本。
> PA0/PA1 为模拟脚（非 5V 容忍），不允许 5V 信号直接输入。

# 11. 红外/电感模拟接口

## 11.1 电感传感器 J_INDUCT

建议保留：

**6P**

```text
1  VCC（默认 3V3_DIG；若模块需 5V 供电，改接 5V_DIG，原理图阶段必须明确标注并评审确认）
2  AIN1
3  AIN2
4  AIN3
5  AIN4
6  GND
```

对应：

- AIN1 → PC0
- AIN2 → PC1
- AIN3 → PA4
- AIN4 → PC5

### 重要要求

VCC 电压与模拟输出范围必须匹配：无论模块采用 3.3V 还是 5V 供电，所有输入必须：

```text
0V ≤ AIN ≤ 3.3V
```

如果外部模块实际使用 5V 运放/传感器：

> 必须在模块内部完成输出限幅/分压，不允许 5V 信号直接进入 H743 ADC。

## J_AD7606

AD7606 建议使用独立 SPI 接口，不与 IMU 强行共用。

接口至少需要：

```text
VCC_5V_A
GND
SPI_SCK
SPI_MOSI / SDI
SPI_MISO / SDO
CS
BUSY
CONVST

```

### 电源

```text

```

不要把 AD7606 AVCC 接到 3V3_A。

# 14. OPA4377 模拟前端接口

OPA4377 属于外接模拟前端模块时，主控板只需要：

- 电源
- GND
- 模拟输入
- 模拟输出

推荐：

```text
3V3_A / 5V_A
GND
AIN
AOUT
```

如果 OPA4377 由 5V 供电，则必须确保其输出送入 H743 ADC 或其他 3.3V 逻辑 ADC 前满足：

```text
VOUT ≤ 3.3V
```

OPA4377 不要求专用 LDO，可使用已经规划好的 `3V3_A` 或 `5V_A`。

 ↓

分压后最大电压必须始终满足：

```text

```

- ADC 输入阻抗
- 分压功耗
- RC 滤波

# 23. 接口保护建议

## 23.1 数字高速信号

SPI、编码器等外部信号根据线长考虑：

```text
MCU
 │
22~100Ω 串联电阻
 │
连接器
```

具体阻值根据实际波形调试。

## 23.2 模拟输入

推荐：

```text
接口
 │
串联小电阻
 │
RC低通
 │
ADC
```

同时必须保证输入绝对不会超过 3.3V。

## 23.3 外部接口 ESD

经常插拔的外接端口可考虑低电容 TVS/ESD 器件。

但：

> 高速 SPI 与高精度模拟输入不能无脑增加高寄生电容 TVS。

选择保护器件时要同时考虑：

- 漏电
- 电容
- 钳位电压
- 传输速率

# 24. 地线规划

禁止简单理解为：

> “模拟地全部切开、数字地全部切开”。

重点应该是控制回流路径。

## 24.1 电机地

外部电机驱动的大电流地：

```text
电池
 ↓
电机驱动
 ↓
大电流回流
```

不要让它经过：

- AD7606 区域
- IMU 区域
- H743 VREF 区域

## 24.2 模拟区域

ADC、OPA、IMU 尽可能形成独立的物理区域。

目标：

```text
Buck
电机驱动
数字高速
      ↓
     隔离
      ↓
ADC / OPA / IMU
```

# 25. 去耦要求

## STM32H743

每个 VDD 电源脚附近设置本地陶瓷去耦。

VDDA、VREF+ 单独重点处理。

## TPS54627DDAR

- VIN 旁路电容必须贴近芯片
- 输出电容靠近电感/芯片
- 严格按照 TI 推荐布局

## TPS54325PWPR

- VIN 本地陶瓷电容
- VOUT 本地陶瓷电容
- 电感靠近 SW

## TPS7A2033PDBVR

- 输入电容紧靠 IN/GND
- 输出电容紧靠 OUT/GND（通常 1µF 陶瓷电容即可保持稳定）
- 按数据手册满足最小负载电容要求
- SOT-23-5 封装，无底部散热焊盘，依靠引脚和 PCB 铜皮散热

## 外接 IMU

接口侧至少预留：

```text
100nF
1µF
```

并靠近 IMU 模块电源入口。

# 29. 核心设计结论

### 电源

**12V → TPS54627DDAR → 5V**

**5V → TPS54325PWPR → 3V3_DIG**

**5V 独立滤波 → TPS7A2033PDBVR → 3V3_A**

不再采用：

```text
5V → 3V3_DIG → 3V3_A
```

作为模拟电源主路径。

### 模拟电源

- AD7606 使用独立 `5V_A_ADC`
- H743 VDDA / VREF+ 使用 `3V3_A`
- IMU 使用 `3V3_A`
- OPA4377 根据模块设计选择 `3V3_A` 或 `5V_A`

### 外设

所有电机驱动、ADC、运放、IMU、编码器、传感器等均按**外接模块**处理。

主控板重点解决：

> **电源 + 接口 + 电平 + 保护 + 滤波 + 地回流。**
