# STM32H7_Car 电源部分全元件审查报告

- **审查对象**：`STM32H7_Car.kicad_sch` 中三个电源模块的**全部元件**（IC 引脚连接、电阻、电容、电感、封装、电池检测分压）
  - U1 = TPS54627DDAR：12V → 5V（6A 同步 Buck，D-CAP2，650kHz）
  - U2 = TPS54325PWPR：5V → 3.3V（3A 同步 Buck，D-CAP2，700kHz）
  - U3 = TPS7A2033PDBVR：5V → 3.3VA（300mA LDO，模拟电源）
- **审查依据**：TI 官方数据手册（`tps54627.pdf` / `tps54325.pdf` / `tps7a20.pdf`）；分析工具为 kicad-happy skill 的 `analyze_schematic.py`，并逐网络核对了连接关系。
- **结论**：**2 处容值错误（C15/C16 应为 1µF）**、**1 处设计缺陷（L1/L2 未指定封装）**、**1 项耐压建议（C1）**；其余全部元件（含反馈分压、EN/PG 网络、电感值、IC 引脚连接与封装）经数据手册核对**正确**。**错误项已全部在原理图中修复**（修改后已经 analyze_schematic.py 复验通过）。

---

## 1. 错误项（必须修改）

### 1.1 容值错误

| 位号 | 位置 | 当前值 | 正确值 | 封装 | 依据 |
|------|------|--------|--------|------|------|
| **C16** | U1 (TPS54627) VREG5 引脚 → GND | 0.1µF / 0603 | **1µF**，X7R，耐压 ≥16V | 0603（无需改封装） | TPS54627 "VREG5 Capacitor Selection"：**"A 1-µF ceramic capacitor must be connected between the VREG5 to GND pin for proper operation"** |
| **C15** | U2 (TPS54325) VREG5 引脚 → GND | 0.1µF / 0603 | **1µF**，X7R，耐压 ≥16V | 0603（无需改封装） | TPS54325 引脚功能表（VREG5, pin 3）：**"A capacitor (typical 1µF) should be connected to GND."** |

> **风险**：VREG5 是片内 5.5V LDO 输出，经内部二极管给 VBST 自举电路供电。电容缩水 10 倍会导致内部 LDO 不稳、栅驱动电压跌落，可能引起开关异常。属"能工作但不可靠"的隐患。

### 1.2 设计缺陷：电感未指定封装（已修复）

| 位号 | 值 | 选定型号 | 状态 |
|------|-----|---------|------|
| **L1** | 3.3µH | 长江微电 FEXL0530A-3R3M（LCSC: C5378512，Isat 9.5A / Irms 8.1A / DCR 23.1mΩ） | ✅ 已指定封装并填入 LCSC 属性 |
| **L2** | 2.2µH | 震东 ZD0520-2R2M（LCSC: C46956540，Isat 5.5A / Irms 4A / DCR 58mΩ） | ✅ 已指定封装并填入 LCSC 属性 |

两颗电感共用新建封装 `Library:L_Molded_5x5mm_FEXL0530A_ZD0520`（焊盘 1.18×4.70mm，间距 3.31mm，取自 C5378512 的立创官方 ECAD 数据；ZD0520 无官方 ECAD，同为 5×5mm 一体成型电感，打板前建议对照实物/手册确认）。

### 1.3 耐压建议（非硬性错误）

- **C1**（+12V 输入 22µF/0805）：数据手册要求输入陶瓷电容 >10µF 且**耐压大于最大输入电压**。0805/22µF 若选 16V 耐压，12V 直流偏压下有效容值可能跌破 10µF 下限。**建议选 25V 及以上耐压（更稳妥为 35V / 1206 封装）**。

## 7. 审查方法与说明

- 使用 kicad-happy skill 的 `analyze_schematic.py` 提取元件、网络与检测到的电源子电路，再对照三份 TI 数据手册的引脚功能表、绝对最大额定值、推荐元件表（Table 1/Table 2）逐元件人工核对。
- U3 (TPS7A20) 的引脚定义直接对照了数据手册 DBV 封装引脚图（Figure 4-4），排除了自定义库符号引脚映射错误的风险。
- 自动化脚本的两条"输出电压不匹配"告警（估算 3.97V / 2.59V）经核实为**误报**：脚本使用了启发式 Vref=0.6V，而两颗芯片实际 Vref=0.765V，原理图分压电阻与手册推荐表完全一致。
- **更正上一版报告**：上一版曾建议"将 L2 改为 3.3µH"，该结论基于 `pdftotext -layout` 错位的表格文本；经 `-raw` 模式重新提取 TPS54325 Table 2 确认 **3.3V 输出档推荐 L1 = 2.2µH**，L2 的感值是正确的，请勿改动。
- 未覆盖项：电感的具体型号（MPN）与饱和电流无法从原理图验证，需在 BOM 中确认；PCB 布局审查（输入回路面积、VREG5/自举电容位置等）需待 PCB 文件完成后另行检查。
