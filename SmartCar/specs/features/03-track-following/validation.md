# Phase 03: 电磁循迹控制链 — 验证

| # | 检查项 | 方法 | 通过标准 | 关联需求 |
|---|---|---|---|---|
| V-1 | 编译零警告 | `MDK-GCC/build.sh` | 构建通过、无 warning | TC-1~TC-5 |
| V-2 | 电感采集与滤波 | 停车状态看屏幕 HOME/ADC_ERR 页 | 4 路电感值随手在磁场附近移动而变化，无跳变毛刺；远离赛道时 4 路均趋近 0 | FR-1 |
| V-3 | 偏差计算 | 停车状态将小车在赛道上方左右平移，看屏幕偏差值 | 偏差随位置单调变化，居中≈0，左右极限约 ±100；磁场全无时偏差归 0（除零保护） | FR-2 |
| V-4 | 对称度输出 | 停车状态看屏幕/串口数据 | 电感对称时 symmetry 接近 0，单侧偏移时增大 | FR-3 |
| V-5 | 方向环响应 | 串口发 `d` 导出走行数据（或屏幕观察 track_out） | 弯道处 track_out 与偏差同向且不超过 ±1000 | FR-4 |

| V-10 | 滤波器行为 | 串口导出数据分析 | 编码器速度曲线平滑无高频毛刺；静止时陀螺 y 经高通后角度不随零偏线性漂移 | FR-10 |

## 自动化验证

- 构建基线（全项目统一）：

  ```bash
  cd SmartCar/MDK-GCC && ./build.sh
  ```

  通过标准：编译链接成功、零警告（对应 `AGENTS.md` 验证基线）。

## 人工验证步骤

1. 烧录固件（`MDK-GCC/flash.sh` 或 Keil 下载），电池上电，保持车辆静止完成 IMU 校准。
2. **停车观测**：屏幕 HOME 页确认 4 路电感、电池电压显示合理；将车放上赛道，左右平移观察偏差值（V-3）。
3. **空转观测**：按 K1 起跑，架空车轮，确认两轮正转、速度闭环稳定（V-7、V-8）。
4. **直线跑道**：低速档起跑，车辆沿电磁线直行，左右摆幅小（V-5、V-6）。
5. **弯道观测**：入弯时内侧轮明显减速、车辆平顺过弯，出弯回正不振荡（V-5、V-6）。
6. **出赛道保护**：运行中将车抬离赛道，车辆立即停车不蠕行（V-7、FR-9）。
7. **数据复盘**：停车后串口发 `d` 导出 CSV，检查偏差/方向输出/速度曲线符合上述各项（V-5、V-10）。

## 回归检查

- 本阶段任何改动不得破坏：
  - TIM15/TIM6 优先级 0 互不抢占（硬性约束 3）——改后需确认采样器与 SPI4 无交错。
  - 2 ms 控制拍周期——`App_ControlISR` 执行耗时不允许逼近 2 ms。
  - 占空比 0~10000 万分比对外语义（硬性约束 4）。
  - [Phase 04 元素状态机](../04-element-fsm/validation.md) 依赖的全局量：`adc_filted`、`symmetry_y`、`Distance`、`angle_x` 清零接口。
  - 菜单/串口调参对 `KP_v/KI_v/KP_x/base_speed` 的读写通路（Phase 06）。
