## 验证方式与回退

- 两 LCD 配置构建在临时完整源码副本中执行原 `MDK-GCC/build.sh`，副本中的配置分别置 0/1；
  生产配置不改，结果分别记录。此方式不要求改构建脚本或引入格式化器。
- 每组首先核对映射/固定名/作用域，再审查表达式和副作用顺序，运行现有回归；不通过时停止
  该组提交，定位为名字/测试适配问题后修正。涉及行为修复或新设计时先询问并提交规约增量。
- 不用全仓库回滚、清理或重置处理失败；仅撤回本任务明确修改且未混入用户改动的文件。
  代码实施前重新检查工作区与基线漂移；发现同名改动先合并进规约后实施。
- 源码调试行号和符号名会变化，运行数据协议和持久化兼容不变；本仓库内全部调用整体迁移，
  不提供旧 C 名称兼容层。
