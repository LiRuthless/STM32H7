# Phase 08: 存储链修复 — 验证

## 验证清单（Scorecard）

| # | 检查项 | 方法 | 通过标准 | 关联需求 |
|---|---|---|---|---|
| V-1 | Flash 初始化接入 | 代码审查 + 上电串口 | `App_Init` 中 `BSP_Flash_Init` 位于 `Param_Load` 之前；上电后串口无 Flash 错误提示（正常接板时） | FR-1 |
| V-2 | Flash 初始化失败降级 | 人工（拔/短接 W25Q64 相关引脚或临时屏蔽后烧录，测毕恢复） | 串口输出明确错误；菜单/循迹可继续，参数用默认值 | FR-1, FR-2 |
| V-3 | 参数持久化生效 | 上机：菜单调参 → 断电 → 重启 | 重启后菜单调参页显示值为断电前修改值（非默认值 0） | FR-2, FR-3 |
| V-4 | 串口调参落盘 | 上机：停车态发 `vp15` → 断电 → 重启 → 菜单/回显核对 | 重启后 `KP_v` 为 0.15；每次命中命令有回显，落盘失败有错误提示 | FR-4 |
| V-5 | 数据记录生效 | 上机：按启动键跑一段 → 停车 → 串口发 `d` | CSV 输出非空、行数与时长吻合（约 1000 行/秒），字段无全零异常 | FR-6 |
| V-6 | 日志失败可观测 | 人工（同 V-2 故障注入）：按启动键 | 串口提示"日志不可用"，车辆循迹与停车保护正常 | FR-6 |
| V-7 | fan_duty 链一致 | 上机（接通取舍）：菜单改 `fan_duty` → 运行观察风扇 | 风扇转速随参数变化；或（裁剪取舍）菜单/参数表已无该项，编译无残留引用 | FR-5 |

## 自动化验证

- `MDK-GCC/build.sh` 构建通过、**零警告**（每次提交前必跑）。
- 代码审查确认：全工程 `BSP_Flash_Init` 存在且仅有一个调用点（`App_Init`）。

## 人工验证步骤

1. 烧录新固件，串口 115200 打开终端。
2. 上电：确认无 Flash 错误提示（V-1）；进入菜单调参页修改 `KP_x` → BACK 保存 → 断电重启 → 核对保持（V-3）。
3. 停车态串口发 `vp15`，回显 `vp=15`；断电重启，菜单或再次查询确认生效（V-4）。
4. 按启动键短跑 → 停车 → 发 `d` 导出 CSV，检查行数与字段（V-5）。
5. 按 Group 3 取舍验证 `fan_duty`（V-7）。
6. （可选，有条件时）故障注入验证降级路径（V-2、V-6）。

## 回归检查

- 循迹控制行为不变：未改任何控制系数与状态机逻辑，直道循迹与已验证的十字/右环岛行为与整改前一致。
- 菜单翻页/调参/回显流程不变（除新增错误提示外）。
- 看门狗不复位：参数保存的阻塞擦写仍在停车态发生，运行中（IWDG 约 6s 窗口）无新增阻塞点。
- 既有已存参数（若有）可被正常读出（布局/CRC 未变）。
