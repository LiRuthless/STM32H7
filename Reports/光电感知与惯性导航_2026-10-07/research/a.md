# A：光电权重法与差比和法研究正文

本节已按共同约定核验：车体横向左为正；阵列从右到左，位置为 `y=[−0.02,−0.01,0,0.01,0.02] m`；处理后的目标线响应 `q_i∈[0,1]` 越大越接近目标线。以下公式以非负、已逐通道标定的响应为前提。标记【来源支持】、【数学推导】、【工程建议】、【报告假设】区分证据性质。

## 1. 两种名称不等于唯一公式

【来源支持】Pololu 官方 QTR 文档给出以通道索引乘 1000 为位置权重的归一化加权平均，并说明传感器间距相对线宽合适时，其估计设计为单调，可用于闭环控制。[Pololu QTR 官方说明](https://www.pololu.com/docs/0j19/all)。本文改用实测横向位置 `y_i`，随后归一化到 `e∈[−1,1]`；这只是单位和原点变换。

“权重法”至少可能指：① `Σw_i q_i` 的未归一化加权和；② `Σy_i q_i/Σq_i` 的位置质心；③先二值化再按状态表赋偏差。①将线位置与响应总强度混合；②允许强度整体变化时保持位置；③会丢失连续幅值，且状态表不能自动外推。本文固定采用②，不将三种定义混用。

“差比和”一般表达左右差除以左右和，但左右量可能是单通道、组内求和或组内均值，正负号也常随接线或编号相反。左右通道数相等时，组和与组均值所得比值相同；不等时直接比较组和会引入偏置。本文固定采用左右组均值，中心通道不进入公式：

$$L=\frac{1}{N_L}\sum_{y_i>0}q_i,\qquad R=\frac{1}{N_R}\sum_{y_i<0}q_i,\qquad e_{\rm dos}=\frac{L-R}{L+R}.$$

`L,R,e_dos` 均无量纲，左侧响应较强时输出为正。另一种把中心响应 `C` 加入分母的版本 `(L−R)/(L+R+λC)` 能降低中心附近增益，但已是不同算法；不能拿它的参数和本文版本直接互换。

## 2. 权重法：公式、算例与适用性

$$S=\sum_i q_i,\qquad e_y=\frac{\sum_i y_iq_i}{S},\qquad e_{\rm centroid}=\frac{e_y}{y_{\max}},\quad y_{\max}=0.02\ {\rm m}.$$

输入是各通道响应及实际安装位置；输出 `e_y` 是感知阵列平面中的目标响应质心（m），`e_centroid` 是控制用归一化偏差。它不是天然等于车轴中心到赛道中心的几何距离；若阵列位于车轴前方、航向有夹角、线形状不对称或视场被截断，二者不同。

【报告算例】令 `q=[0.05,0.10,0.20,0.80,0.90]`。总响应 `S=2.05`；位置加权和为

$$-0.02\times0.05-0.01\times0.10+0\times0.20+0.01\times0.80+0.02\times0.90=0.024\ {\rm m}.$$

因此 `e_y=0.024/2.05=0.011707317 m`，即左偏约 11.707 mm；`e_centroid=0.585365854`。注意分子不是 0.0245；以上逐项加法应作为实现验证基准。

【数学推导】设连续目标响应 `q(y)=A h(y−y_0)`，`h` 关于零对称，目标响应全部落在观测范围内，则

$$\frac{\int yq(y)\,dy}{\int q(y)\,dy}=y_0+\frac{\int uh(u)\,du}{\int h(u)\,du}=y_0.$$

这给出质心法在对称单线、覆盖完整时的理论依据；离散传感器相当于对积分求和，有限间距、非均匀响应、背景残留和阵列边缘截断会产生偏差。不能由连续模型推断任何间距都可行。应把阵列横扫实际赛道，记录“真实横移—输出”曲线，核验单调区间、斜率和残差。

因为 `q_i≥0`，`e_y` 是 `y_i` 的凸组合，必在最小与最大传感器位置之间；这保证输出有界，却不能保证线路唯一。两条对称支线或全黑区域也能得到 `e=0`，必须保留原始空间模式以识别交叉口、宽线或歧义。

## 3. 差比和法：公式、算例与适用性

同一组数据中，`L=(0.80+0.90)/2=0.85`，`R=(0.05+0.10)/2=0.075`，故

$$e_{\rm dos}=\frac{0.85-0.075}{0.85+0.075}=\frac{0.775}{0.925}=0.837837838.$$

输出也指向左，但它与质心的 `0.585365854` 并不等尺度。差比和丢弃了组内“靠近中心还是靠近外侧”的信息。例如 `q=[0,0,0,1,0]` 与 `[0,0,0,0,1]` 的差比和都为 1；质心则分别为 0.5 与 1。PID 参数必须随算法变化重新评估。

【数学推导】非负且 `D=L+R>0` 时 `|L−R|≤L+R`，故 `e_dos∈[−1,1]`。共同乘性系数 `c>0` 满足 `(cL−cR)/(cL+cR)=e_dos`，因此未饱和的共同增益变化可消除；共同加性背景 `b` 却产生 `(L−R)/(L+R+2b)`，使灵敏度下降。左右增益不一致还会造成零点偏置。所谓“抗光照变化”只能在变化可近似为共同乘法、且标定正确的条件下成立。

把左右组响应写成横移 `y_0` 的函数，

$$\frac{de_{\rm dos}}{dy_0}=\frac{2(RL'-LR')}{(L+R)^2}.$$

在所关心区间内若 `L'≥0,R'≤0`，并且至少一侧有有效变化，该输出局部单调。在对称中心附近，若 `L=L_0+\kappa y_0,R=L_0−\kappa y_0,L_0>0`，则 `e_dos≈(κ/L_0)y_0`。`κ/L_0` 的单位是 `m⁻¹`，可由实际横扫标定拟合；线宽、光斑宽度、组布局及安装高度都会改变该斜率。远离中心可能两侧都弱、都饱和或单侧占优，此时公式虽可有界，位置分辨能力却消失。

【来源支持】Hamamatsu 的 PSD 技术说明给出连续电阻型位置探测器 `X=(I_2−I_1)/(I_1+I_2)·L_x/2`，并说明归一化可消除理想模型中的光强影响。[Hamamatsu PSD 技术说明，公式 1-3、2-2](https://www.hamamatsu.com/content/dam/hamamatsu-photonics/sites/documents/99_SALES_LIBRARY/ssd/psd_kpsd9001e.pdf)。PSD 的电流分流机制与分立循迹阵列不同；该资料支持差除和在特定光学模型中的数学用途，不能证明本阵列输出与真实横向距离严格线性，更不能证明小车车速。

## 4. 参数、灵敏度、噪声与响应

【数学推导】质心对通道扰动的灵敏度是

$$\frac{\partial e_y}{\partial q_i}=\frac{y_i-e_y}{S}.$$

若扰动较小、相互独立，通道方差为 `σ_i²`，一阶近似为

$$\operatorname{Var}(e_y)\approx\frac{\sum_i(y_i-e_y)^2\sigma_i^2}{S^2}.$$

小总响应放大噪声；距当前质心较远的通道误差贡献较大。若通道相关，须用雅可比 `JΣJᵀ` 而不能简单相加。不能断言“加更多通道必然更稳”：新通道若主要看到背景噪声，反而会引入扰动。

差比和对左右量的偏导数为

$$\frac{\partial e_{\rm dos}}{\partial L}=\frac{2R}{D^2},\qquad\frac{\partial e_{\rm dos}}{\partial R}=\frac{-2L}{D^2}.$$

左右独立时 `Var(e_dos)≈4(R²σ_L²+L²σ_R²)/D⁴`。例如 `L=R=0.5,σ_L=σ_R=0.01`，`σ_e≈0.01414`；若共同缩小为 `L=R=0.05`、绝对噪声仍为 0.01，则 `σ_e≈0.1414`。这说明归一化并不能恢复低信噪比；必须有有效分母门限。

| 参数或选择 | 作用及代价 | 选择依据 |
|---|---|---|
| 物理位置权重 `y_i` | 决定质心单位和空间意义；夸大外侧权重会改变响应形状 | 测量安装位置；非均匀阵列按真实坐标。额外非线性权重应作为另一种映射验证 |
| `y_max` 归一化 | 调整无量纲误差尺度和 PID 增益；不增加信息 | 固定几何范围，调参时记录算法及尺度 |
| 逐通道增益/零点标定 | 去除器件差异；过小黑白跨度使归一化噪声变大 | 实际地面、实际高度、多次样本；跨度须显著超过噪声 |
| 去噪门限 `q_i<τ` 置零 | 减少背景噪声，但产生偏差和阈值附近跳变 | 由背景响应分布及可接受误检率确定，配合横扫连续性验证 |
| `q_i^γ` 或软阈值 | `γ>1` 更强调强响应；可能压掉弱有效通道、放大峰值竞争 | 本文默认 `γ=1`；确有宽线/背景问题再比较误差、单调性和抖动 |
| 有效分母门限 `S_min,D_min` | 防止弱信号除法爆噪；门限太高会拒绝有效边缘 | 依据上述噪声传播式、目标输出噪声上限和失线分布选取 |
| 左右分组 | 均值避免数量偏置；组内位置丢失 | 先标定 `e_dos(y)`；需宽量程位置时优先质心 |
| 时间低通或平均 | 降低高频噪声，增加延迟与相位滞后 | 同时测噪声和延迟；长度 `M` 的因果等权平均群延迟为 `(M−1)T/2` |

【来源支持】现行 QTR `readLinePrivate()` 源码有独立的噪声参与门限、在线判定门限，以及丢线后按上次方向给出边界位置的处理。[Pololu 官方实现](https://pololu.github.io/qtr-sensors-arduino/_q_t_r_sensors_8cpp_source.html)。这些是特定库的工程选择，本文不把其数值搬作通用参数。

【工程建议】逐通道门限可先以背景均值与标准差构造 `τ_i=μ_bg,i+kσ_bg,i`，`k` 根据允许误检率选取；只有背景近似高斯且稳定时才可将其解释为尾概率。更可靠的做法是使用实测背景分位数，再验证弱线能被保留。静止采样得到的门限还应复测振动、地面变化、环境光变化。

## 5. 可行性、可信度与“快”的边界

【数学推导】上面的质心恒等式和差比和局部单调性，分别说明这两种观测量可在明确的单线、有效信号及几何条件下用于反馈。进一步给出一个有限的闭环可行性例子：直线轨迹、常速 `v>0`、小横偏 `Y` 和小航向 `ψ`、传感器位于车轴前 `ℓ>0 m`，且理想执行器可直接实现航向角速度。阵列测得线相对位置约为 `e_y≈−Y−ℓψ`。取正转向增益 `\dot ψ=K e_y`，`K>0` 的单位是 `rad/(m·s)`，则

$$\dot Y=v\psi,\qquad\dot\psi=-K(Y+\ell\psi),\qquad\lambda^2+K\ell\lambda+Kv=0.$$

两系数为正，连续时间线性化系统渐近稳定。若差比和在中心有正斜率 `h=de/dy_0>0`，使用 `\dot ψ=k e`，等效 `K=kh`，同一结论成立。这是本报告自推导的可行性例证，未使用车辆实验数据；它不包含轮胎打滑、转向带宽、执行器延迟、采样、限幅或大曲率，不能替代 PID 稳定性验证。`ℓ=0` 时该纯比例模型无阻尼，提示布局及动态补偿的重要性。

该模型的 `ω_n=√(Kv)`、`ζ=Kℓ/(2√(Kv))` 表明，提高车速并不只要求“算得更快”，还改变闭环阻尼；真正能否高速循迹取决于感知提前量、采样与执行延迟、转向能力、附着力、线形状及赛道条件。

| “快”的含义 | 本报告可以论证什么 | 尚须验证什么 |
|---|---|---|
| 计算执行速度 | 两法均需一次遍历，复杂度 `O(N)`，少量乘加和一次有效除法 | 目标主控驱动、浮点/定点实现、任务调度下的最坏耗时；Python 时耗不等于 STM32 时耗 |
| 控制响应速度 | 局部斜率、噪声传播及理想模型解释增益和响应关系 | 含采样、滤波、转向执行器和限幅的实测响应/稳定裕度 |
| 实际运动速度 | 公开实现与条件推导说明可用于循迹反馈 | 没有核验到本公式、同类阵列和条件齐全的量化高速实验；不宣称某 m/s 已被证明 |

## 6. 方法选择表与必须保留的异常状态

| 比较项 | 归一化位置质心 | 左右组差比和 |
|---|---|---|
| 最合适条件 | 有多通道有效幅值，需覆盖阵列范围的横向位置估计 | 左右响应在目标区间互补且局部单调，主要需中心附近转向误差 |
| 优点 | 保留各位置作用，可输出 m，连续单线模型有清楚的几何意义 | 计算和分组简单，有界，理想共同乘性增益变化被消除 |
| 限制 | 背景残留、边缘截断、多线导致偏差；弱总响应放噪声 | 组内位置不可辨，可能提前饱和；依赖布局和线宽，通常不能直接输出 m |
| 中心仅一通道有线 | `q=[0,0,1,0,0]` 给出有效 `e_y=0` | `L+R=0`，本定义无效；不能把 0/0 当成已确定居中 |
| 对称多峰或全覆盖 | 可能输出 0，需形态判定 | 也可能输出 0，需形态判定 |
| 选择依据 | 横扫单调性、位置误差和噪声；适合更完整的位置需求 | 横扫有效区间、中心斜率、饱和范围及噪声；适合布局明确的局部反馈 |

【工程建议】算法应同时输出 `valid`、`reason`、`strength` 与偏差，而不是只给一个数字。分母过小应判无效；加一个任意 `ε` 虽能避免除零，却会把“没有证据”伪装成接近零的偏差。质心有效、差比和无效且中心响应较强时，可由明确写出的状态机使用质心回退，或进入 `center_only` 保守策略；这属于混合算法，必须在记录中标明使用的方法。丢线搜索可参考最后可信方向，但旧偏差不是新测量，搜索速度和持续时间需限幅；多峰/全覆盖应由线路任务逻辑处理。

### 可直接用于离线 HTML 的公式文本

```text
S = Σ q_i
e_y [m] = (Σ y_i·q_i) / S
e_centroid = e_y / y_max ; y_max = 0.02 m
L = mean(q_i | y_i > 0) ; R = mean(q_i | y_i < 0)
D = L + R
e_dos = (L − R) / D

∂e_y/∂q_i = (y_i − e_y)/S
Var(e_y) ≈ Σ[(y_i − e_y)²·σ_i²]/S²
∂e_dos/∂L = 2R/D² ; ∂e_dos/∂R = −2L/D²
Var(e_dos) ≈ 4(R²σ_L² + L²σ_R²)/D⁴
de_dos/dy_0 = 2(R·L′ − L·R′)/D²
L ≈ L_0 + κy_0 ; R ≈ L_0 − κy_0 ⇒ e_dos ≈ (κ/L_0)y_0

理想单线连续质心：∫y·q(y)dy / ∫q(y)dy = y_0（响应对称、全部被覆盖）
理想小角度闭环：e_y ≈ −Y − ℓψ ; dY/dt = vψ ; dψ/dt = K·e_y
特征方程：λ² + Kℓλ + Kv = 0（K>0、ℓ>0、v>0 时线性化渐近稳定）
ω_n = √(Kv) ; ζ = Kℓ/[2√(Kv)]
```
