# 基线与报告差异

基线68cb508只改变八份治理/入口文档，App/BSP/Core、IOC、测试和工程配置未变。
开始时硬件PCB/工程有在途改动；已有未跟踪报告和大量build产物不纳入本轮。

| 审计项 | 当前判定 | 去向 |
|---|---|---|
| M02、旧D04 SPI2 15MHz | 68cb508已更正为初始化1.875MHz，提供7.5MHz接口但活动链未调用 | docs平台及通信，波形仍待验 |
| M07验证政策 | 68cb508已明确按需软件验证、减少脚手架 | docs验证指南引用AGENTS，不恢复旧全量门禁 |
| M08主文档状态/资料路径 | 主入口已整理；部分Phase仍保留旧当前措辞 | G2/G3逐页处理 |
| H01 P08 V6/V9、H02旧日志验收 | 后续P14已替代；旧步骤仍易误用 | 日志/运行docs承接，旧结果保留 |
| H03/D02/R02 DL1B及超时 | 代码阻塞与旧非阻塞要求冲突，仍存在 | D02，不能直接改成已批准阻塞 |
| H04/D05 IOC栈 | 实际双工程8KB；IOC仍0x400 | D05独立配置任务 |
| H05参数v2/v3 | v3代码已存在，旧现行字段表分流不足 | docs参数页，历史v1/v2保留时代 |
| H06 R01～R07入口 | 研究报告有证据，统一状态入口不足 | docs已知问题 |
| M01/D01 UART | 未发送约定与len-TxXferCount相反 | D01待决定 |
| M03首因 | 累计保护位先于锁存，抢占窗口仍在 | D07待决定 |
| M04停车文本 | 当前是数值和日志摘要，旧精确文本尚未明确撤销 | D09待决定，docs列现状 |
| M05保存重试 | 擦写失败不保证旧镜像可重启迁移；成功才清dirty | docs明确保证边界 |
| M06 IMU验证 | CSV不含angle_x/accel_x | 调试器观察；不改格式 |
| D03/R05风扇 | 状态更新不代表停车PWM即时写出 | 待决定 |
| D06显示、N01路径 | 显示是低通值；旧研究pid链接失效 | 仅修措辞及带日期现行导航 |
| F24回绕 | 发送端检查与接收方责任不清 | D08待决定 |
| R01/R03/R04/R06 | 已知数值、IMU、分帧、镜像行为尚未修复 | 修复台账；不由结构完成推定关闭 |
| R07/R08 | 原样本缺失；R08已有复核机制而非所有注释永不出错 | 保留证据、逐项核对 |

旧版本算法、配置、日志格式及旧构建数值不因年代不同自动成为新缺陷。P09/P10规划不冒充已实现；32项标定-1、缺ESP32桥接、AC5/实机待验不是本轮可关闭事项。
