# MCU 引脚分配表（AI8051U / STC32G）

> 依据 `project/code` 与 `libraries/zf_device` 中的实际配置整理。

## 驱动电机

| 引脚 | 功能 | 说明 |
|------|------|------|
| P2.7 | 左轮 PWM | PWMB_CH4，17 kHz |
| P2.6 | 左轮方向 DIR | 推挽输出 |
| P2.5 | 右轮 PWM | PWMB_CH3，17 kHz |
| P5.1 | 右轮方向 DIR | 推挽输出 |
| P2.2 | 负压电机（风扇）PWM | PWMA_CH2P，100 Hz |

## 编码器

| 引脚 | 功能 | 说明 |
|------|------|------|
| P3.5 | 左轮编码器脉冲 | TIM1 编码器 |
| P2.4 | 左轮编码器方向 | GPIO 输入 |
| P3.4 | 右轮编码器脉冲 | TIM0 编码器 |
| P1.1 | 右轮编码器方向 | GPIO 输入 |

## ADC（电磁电感 / 按键 / 电池）

| 引脚 | 功能 | 说明 |
|------|------|------|
| P0.5 | 电感通道 1 | ADC_CH13，12 位 |
| P0.6 | 电感通道 2 | ADC_CH14，12 位 |
| P0.0 | 电感通道 3 | ADC_CH8，12 位 |
| P0.2 | 电感通道 4 | ADC_CH10，12 位 |
| P1.4 | 按键 ADC 1（方向键+确定） | ADC_CH4，12 位 |
| P1.3 | 按键 ADC 2（复位+返回） | ADC_CH3，12 位 |
| P0.3 | 电池电压检测 | ADC_CH11，12 位 |

## 串口（UART1，调试 + 无线模块共用）

| 引脚 | 功能 | 说明 |
|------|------|------|
| P3.1 | UART1 TX | 115200 bps |
| P3.0 | UART1 RX | 115200 bps，接收中断使能 |
| P3.6 | 无线串口 RTS | 无线模块流控 |

## IMU660RB 六轴（软件 SPI）

| 引脚 | 功能 | 说明 |
|------|------|------|
| P3.3 | SPC (SCK) | 软件 SPI 时钟 |
| P3.2 | SDI (MOSI) | 软件 SPI 主机输出 |
| P4.3 | SDO (MISO) | 软件 SPI 主机输入 |
| P3.7 | CS | 片选 |

## DL1B 激光测距（软件 IIC）

| 引脚 | 功能 | 说明 |
|------|------|------|
| P1.0 | SCL | 软件 IIC 时钟 |
| P4.2 | SDA | 软件 IIC 数据 |
| P4.7 | XS | 使能/复位引脚 |

## IPS114 显示屏（硬件 SPI0）

| 引脚 | 功能 | 说明 |
|------|------|------|
| P1.7 | SCK | SPI0 时钟，20 MHz |
| P1.5 | MOSI | SPI0 数据 |
| P5.3 | CS | 片选 |
| P5.2 | DC | 命令/数据选择 |
| P1.2 | RST | 复位 |
| P1.6 | BLK | 背光 |

## 其他

| 引脚 | 功能 | 说明 |
|------|------|------|
| P2.3 | 启动按键 | GPIO 输入，下降沿触发 Start |

> 注：代码中 P1.0 曾定义为蜂鸣器（实际未焊接，未使用），仅作 DL1B 的 SCL 使用。
