## 功能需求

2026-10-18：FR-4按已确认的[g-03-event-gap](g-03-event-gap.md)首个源锚点编码，不伪造时序，不把未ACK可重试帧算作丢失。

<a id="fr-01"></a>

- **FR-1**：SPI/TCP可靠通道独立，转发时重建session、seq、ack和CRC，保持request_id及业务负载内容；除遥测ESP32丢弃字段外不重写STM32内容。接收可靠帧前必须预留后续交付/结果存储额度，队满时不ACK、不接管，或明确返回合法BUSY；不能先ACK后静默丢失。链路ACK不等待业务完成。
<a id="fr-02"></a>

- **FR-2**：保持最多一条未获最终结果的业务调参请求，同时给GET_REQUEST_RESULT等查询保留可前进通路，不能因等待APPLIED阻塞查询或IDLE ACK。STM32 RECEIVED/APPLIED/SAVED及保存事件原样转交；本端不伪造、合并或升级业务状态，不重试业务执行替代传输重发。
<a id="fr-03"></a>

- **FR-3**：UDP队列16包，满时丢旧保新，累计ESP32丢包计数；离线/无订阅直接丢弃计数，断线丢弃未发队列也计入。发送前只更新遥测元数据偏移12的ESP32累计丢弃数，再独立编码UDP序号和CRC；保留session/run_id/记录索引/revision及记录本身，不跨运行拼包。
<a id="fr-04"></a>

- **FR-4**：EVENT队列32条，漏事件须显式上报EVENT_GAP，不以可靠重发重复入队。保留设备提供的run_id/tick/control_sequence/revision和values/status；本端无法重建的历史标未知，禁止伪造完整历史。桥接端缺口报告的字段来源与线格式须先解除G-03门禁；无法接管的可靠事件不先ACK再丢。
<a id="fr-05"></a>

- **FR-5**：会话变化清除旧传输缓存、未应用请求、订阅和导出状态；按[已确认G-02](../02-scb-protocol/g-02-session-change.md)关闭TCP，电脑重连握手获取状态。普通网络断开仅清理该控制连接资源，不重置SPI、不关调试覆盖、不清已生效值。重连不重放旧设置；ESP32重启通过新握手产生新会话，旧帧拒绝。
<a id="fr-06"></a>

- **FR-6**：日志导出窗口1，按电脑LOG_BEGIN/READ/END请求转交；每次只缓存有界块，不预读整份日志。LOG_READ length 1～960、LOG_DATA结构合法、request_id及块内容原样透传。相同请求重传不重复推进整体CRC；最终total_bytes/CRC由STM32产生，本端不伪造成功或以未核验值替代。
<a id="fr-07"></a>

- **FR-7**：导出在控制断开、会话变化或10秒无新有效读取后取消本端状态；本版不新增内部取消操作码，采用任务书允许的STM32自身10秒超时释放路径。独立服务计时，不依赖TCP/SPI必须先断开；重复旧请求不能被当作新读取无限续期。STM32负责停车/收尾许可、起跑清除互斥及释放，本端须用模拟对端验证约定，不宣称已控制真实STM32锁。
<a id="fr-08"></a>

- **FR-8**：公开SPI/TCP/UDP包数、CRC错、截短、重试、队列峰值、UDP丢弃和当前session；串口状态/内部快照接口可取，业务socket无调试文本。不擅自向SCB/1增加统计命令/字段，丢包字段按契约发送。
<a id="fr-09"></a>

- **FR-9**：初始化/驱动失败停止受影响服务并明确报错；普通socket错误仅连接恢复，SPI通信失败重握手。所有故障路径不自动操作EN、不新增停车、不回滚已应用值，既有Flash/安全链优先。

## 技术约束

<a id="tc-01"></a>

- **TC-1**：启动分配一次，数据路径固定池和有界队列；每方向一个可靠帧在途。队列只能在应用拥有的帧槽间转移，绝不由网络修改驱动持有DMA。
<a id="tc-02"></a>

- **TC-2**：调参值/范围、特殊元素、应用控制拍、日志有效性、Flash CRC及车辆互斥仍由STM32负责；ESP32只能校验线格式和本端订阅参数。对端32B不匹配时停止真实数据联调，模拟依96B进行。
<a id="tc-03"></a>

- **TC-3**：所有计时及重建动作须能在网络无业务时推进，不以socket无限等待或SPI忙等作为调度方式；SPI已提交的DMA内存不能因逻辑超时被其他任务重写。

## 接口与非目标

内部事件为完整已验证帧、连接身份、会话变化、单调时间及容量状态；输出为接管许可、目标传输待发帧、队列/统计变化和取消状态。转发可靠性不是业务执行授权，不实现Flash扫描、掉电恢复或控制状态机。
