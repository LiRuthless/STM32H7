## 功能需求

<a id="fr-01"></a>

- **FR-1**：建立从任务书到需求、计划模块、验证项及实际证据的映射；覆盖全部公共向量/CRC/错长/重复/背压/会话变化和ACK与业务结果分离，用独立方法交叉核验，不只自我往返。
<a id="fr-02"></a>

- **FR-2**：在v6.0.0实际构建esp32s3，记录SDK提交/本地状态、编译器/Python/CMake/Ninja版本、配置、静态RAM/Flash、启动内部堆、最小空闲堆和任务栈高水位；对代码/驱动/固定池分别说明，不用“无PSRAM”代替内存证据。
<a id="fr-03"></a>

- **FR-3**：用模拟STM32/电脑先完成独立可执行验证；实机按向量→SPI握手→Wi-Fi上传/导出→运行调参顺序，核对GPIO、Mode0、READY/CS、1024B/8192bit及截短恢复。未解除G-05不得把模拟对端当作现有STM32。
<a id="fr-04"></a>

- **FR-4**：连续至少60秒输入1kHz、每条96B，即原始记录96kB/s，记录输入/接管/发送/丢弃/队列峰值及测试条件；另注入慢TCP、UDP拥堵和断线。判断无静默丢失、内存无持续增长、SPI推进不依赖socket发送；不要求UDP网络绝对零丢包，也不凭队列深度推定吞吐通过。
<a id="fr-05"></a>

- **FR-5**：验证第二控制连接拒绝、UDP无第三方目标、订阅重建、旧设置不重放、会话/重试恢复及导出窗口1；验证APPLIED/保存事件逐字节业务内容透传。导出与模拟/真实STM32原始字节及独立CRC对照一致，失败保留证据，不伪称成功。
<a id="fr-06"></a>

- **FR-6**：交付工程、协议头、向量、本地忽略配置及无密码示例、无空格构建脚本、中文安装/编译/烧录/联调README。说明Windows UDP放行、实际串口/版本核对、测量和恢复流程；实际串口、板卡Flash容量和测量值须有证据，不写猜测默认值为事实。
<a id="fr-07"></a>

- **FR-7**：记录每项实际状态为通过/失败/未执行/阻塞，并附日期、版本、输入、命令或步骤、证据路径和限制。代码/文档按阶段审查、分次提交，仅本工程明确路径、不push。未执行的实机项保持待验，不能勾选总体完成。
