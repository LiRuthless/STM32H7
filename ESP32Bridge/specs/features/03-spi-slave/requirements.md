# Phase 03：SPI从机 — 需求

> 本端SPI服务软件已实现/接入并完成本次178项回归与真实目标构建，待阶段统一审查；实机待验。具体范围/网络消费边界见[阶段报告](../../../docs/validation/phase-03.md)。依据：任务书A/B、共享协议第1～3节、验收3/4。

## 功能需求

- **FR-1**：SPI2_HOST从机，SPI_DMA_CH_AUTO；CS10、SCK12、MOSI11、MISO13，Mode0、8bit、MSB first、全双工。READY14低有效，初始撤销；WP/HD及未使用扩展数据线设-1，不占用GPIO14。PD15/EN保留不自动复位。
- **FR-2**：SPI任务固定Core1、优先级12、事务深度1，在该核初始化驱动并核对ISR归属。使用spi_slave_initialize / spi_slave_queue_trans / spi_slave_get_trans_result；无主机时钟时阻塞等待事务完成，不轮询忙等。
- **FR-3**：驱动持有TX/RX和事务描述期间应用不访问。post_setup只在事务已装载时拉低READY，post_trans撤销READY。回收后验证并处理、准备下一TX/RX和重排事务，再由post_setup发布下一次READY；回调只做IRAM安全GPIO/轻量标志。
- **FR-4**：每事务配置8192bit，对外严格1024B；收回后首先检查trans_len==8192，再做帧长度、CRC、会话及容量检查。截短或非法帧不执行、不ACK，回收并重排恢复；驱动初始化/排队错误明确报错，不发布虚假READY。
- **FR-5**：SPI收到的请求通过固定有界交付接口向桥接层移交；后续事务返回结果，不假设同次响应。没有业务时发送合法IDLE/握手响应，可靠ACK和结果优先于实时路径，不等待socket或电脑连接。
- **FR-6**：离线或没有订阅的遥测直接丢弃计数，不积攒离线记录；可靠帧按独立额度接管。CRC错误、截短、重试和队列峰值能被状态统计采集。

## 技术约束

Group 1已按确认资源及纯规约9ea2351/实现712fb41落地Core1任务6144B栈、静态TCB/初始化信号量；本批按82613f6接入事务/协议，JSON工作区1492B由任务独占。资源推导/目标符号大小不是实机堆栈测量。

- **TC-1**：DMA缓冲固定内部池、启动分配、32bit边界及4B长度倍数；描述与数据生命周期延续至get_trans_result成功返回。无反复分配/socket/阻塞网络发送；按已确认G-06，ISR无JSON，SPI任务仅在回收并取得应用所有权后允许完整有界codec/JSON解析。
- **TC-2**：所有回调调用链IRAM兼容，ISR不打印、不CRC、不JSON、不锁住等待任务；普通解析在回收之后任务上下文执行。
- **TC-3**：实际CS内1024B和SCK必须实测；trans_len可能在超长时饱和，不能仅凭等于8192判定没有多余时钟。按约1.875MHz→约7.5MHz联调，按实际STM32时钟核算，不擅改Mode或引脚。

## 输入输出与非目标

输入为主机CS/时钟及1024B帧，输出为同长TX与READY。上层接管失败不推进可靠ACK；驱动错误不改变车辆停车策略。不轮询PD15/EN复位，不实现STM32 DMA或时钟配置。G-05已从32B不匹配更新为完整布局及对端能力待验；真实联调前须取得证据，模拟和其他合法帧测试可独立执行。
