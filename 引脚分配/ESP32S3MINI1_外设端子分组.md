# ESP32-S3-DevKitM-1 外设端子分组表

下面把 **ESP32-S3-DevKitM-1 / ESP32-S3-MINI-1** 也整理成类似 STM32 的“外设端子分组表”。  
定位：**ESP32 作为 WiFi 协处理器**，通过 **SPI2 从机** 与 STM32H743 通信；SPI3 主机留给 ESP32 自己扩展外设。

---

## 1. STM32 通信端子（8P，SPI2 从机）

> 与 STM32 的“WiFi 调试模块端子（8P，SPI2）”配对使用。  
> 建议统一线序：**5V、GND、CS、SCK、MOSI、MISO、INT、RST**。

| 序号 | 端子名 | ESP32 连接 | 说明 |
|---:|--------|------------|------|
| 1 | 5V | **5V** | ESP32 峰值电流大，必须用主板 5V 供电，不要用 STM32 的 3.3V |
| 2 | GND | **GND** | 与 STM32 共地，必须 |
| 3 | CS | **IO10** | SPI2 从机片选，对应 STM32 PB12 |
| 4 | SCK | **IO12** | SPI2 从机时钟，对应 STM32 PB13 |
| 5 | MOSI | **IO11** | ESP32 接收，对应 STM32 PB15 |
| 6 | MISO | **IO13** | ESP32 发送，对应 STM32 PB14 |
| 7 | INT | **IO14** | ESP32 数据就绪，通知 STM32（对应 PA15） |
| 8 | RST | **EN** | STM32 PD15 控制 ESP32 复位；建议开漏或串 1kΩ，不接也可 |

> SPI2 使用 IO10/IO11/IO12/IO13 时走 **IO MUX 直连**，最高可靠时钟可达 80 MHz。飞线建议先跑 1 MHz，稳定后再提高。

---

## 2. SPI3 主机外设端子（8P）

> ESP32 自己作为 SPI 主机，驱动屏幕、传感器等外设。  
> SPI3 只能走 GPIO 矩阵，最高约 40 MHz。

| 序号 | 端子名 | ESP32 连接 | 说明 |
|---:|--------|------------|------|
| 1 | 3.3V | **3.3V** | 外设供电，注意电流 |
| 2 | GND | **GND** | |
| 3 | SCK | **IO36** | SPI3 主机时钟 |
| 4 | MOSI | **IO35** | SPI3 主机输出 |
| 5 | MISO | **IO37** | SPI3 主机输入 |
| 6 | CS0 | **IO34** | 片选 0，可接屏/传感器 |
| 7 | CS1 | **IO33** | 片选 1，备用 |
| 8 | 备用 | **IO38** | 可作 DC/RST/BLK 等，按外设需要分配 |

> 若使用带 PSRAM 的 **-N4R2** 模组，IO35~IO37 可能被内部 PSRAM 占用，需改用其他 GPIO。DevKitM-1 板载 -N8 型号无此问题。

## 7. 与 STM32 WiFi 端子的配对

STM32 侧“WiFi 调试模块端子（8P）”按统一线序重新定义为：  
**1-5V、2-GND、3-CS、4-SCK、5-MOSI、6-MISO、7-INT、8-RST**。

| STM32 端子 | STM32 引脚 | ESP32 端子 | ESP32 引脚 | 说明 |
|---|---|---|---|---|
| 5V | 主板 5V | 5V | 5V | ESP32 主供电 |
| GND | GND | GND | GND | 共地 |
| CS | PB12 | CS | IO10 | STM32 → ESP32 |
| SCK | PB13 | SCK | IO12 | STM32 → ESP32 |
| MOSI | PB15 | MOSI | IO11 | STM32 → ESP32 |
| MISO | PB14 | MISO | IO13 | ESP32 → STM32 |
| INT | PA15 | INT | IO14 | ESP32 → STM32，数据就绪中断 |
| RST | PD15 | RST | EN | STM32 → ESP32 复位，可选 |

> 注意：STM32 原 WiFi 端子表中的 VCC 写的是 3.3V，实际给 ESP32 供电应改为 **5V**，或 ESP32 单独从主板 5V 取电，只共地。

---

## 8. 关键注意事项

1. **供电**：ESP32 Wi-Fi 工作时峰值电流可超 300 mA，必须用 5V/≥500 mA 供电，不要用 STM32 的 3.3V LDO。
2. **电平**：STM32 与 ESP32 均为 3.3V 逻辑，SPI 直连即可，不要接 5V 到 IO。
3. **SPI 模式**：STM32 主机 SPI2，ESP32 从机 SPI2，配置 **CPOL=0，CPHA=0，MSB First**。
4. **速率**：先 1 MHz 测试，稳定后逐步提高。飞线建议不超过 10 MHz。
5. **RST 线**：ESP32 的 EN 已有上拉和复位按键，STM32 PD15 接 EN 时建议开漏输出或串 1 kΩ，避免推挽冲突。
6. **strapping 脚**：IO0、IO3、IO45、IO46 上电有固定电平要求，本方案只用 IO0 作 BOOT 按键，IO3/IO45/IO46 未使用。
7. **IO26**：-N4R2 型号中 IO26 接内部 PSRAM，不可用于其他功能。
8. **共地**：所有端子组的 GND 必须与主板 GND 连通，电机大电流地与信号地单点汇合。
